⚡ Quick Install — Recommended for Kronos and unmodified 1.12 clients

Patched WoW.exe
Required⚔️ Kronos
A pre-patched WoW.exe with VanillaTweaks and Vanilla Signature Removal already applied. VanillaTweaks improves sound channels, nameplate range, terrain render distance, and Large Address Aware support (up to 4GB RAM). Signature Removal is required for addons that enable auto-login. Replace your original WoW.exe with this file.
⚠️ Tested and recommended for Kronos and unmodified vanilla 1.12 clients. If your client has already been modified, use the Manual Setup below instead.

VanillaFixes + DLL Pack
Required
VanillaFixes is an external launcher that fixes stutter and animation lag caused by the 1.12 client's low-precision timer. Use it to launch the game instead of opening WoW.exe directly. The DLL Pack includes:
  • VfPatcher.dll — core VanillaFixes patcher
  • SuperWoWhook.dll — enables SuperWoW client extensions
  • VanillaHelpers.dll — required for Project Reforged to function
  • UnitXP_SP3.dll — unit frame and XP bar enhancements
  • nampower.dll — eliminates spell queue lag on the 1.12 client

Config.WTF — Recommended Settings
RequiredRendering
Add these lines to your WTF/Config.WTF file before launching. They enable D3D9 rendering, M2 shaders, and threaded model processing — required for the visual patches to display correctly.
SET gxApi "d3d9"
SET M2UseShaders "1"
SET M2UsePixelShaders "1"
SET M2UseThreaded "1"
SET gxColorBits "24"
SET gxDepthBits "24"
SET M2Faster "3"

Open WTF/Config.WTF in a text editor and paste these lines. If any already exist, replace their values with the ones above.

Important: Patches B + D + E are one large environment/world set. Install them together, or not at all.
