What is Project Reforged
The Project

High Definition.
Faithful to the Original.

Project Reforged is a long-term technical initiative dedicated to raising the visual fidelity of the World of Warcraft® 1.12 client — without sacrificing its atmosphere.

It involves restructuring, converting, and integrating high-definition visual elements so they behave naturally inside the original engine, prioritizing stability, immersion, and a coherent, faithful look.

Installation
1

Install Dependencies

Download and install VanillaHelpers (mandatory) and DXVK (strongly recommended) for best stability.

2

Choose Your Modules

Download the patch modules you want and place them inside your WoW Data folder.

3

Launch & Play

Start the game and experience Azeroth reforged. No additional configuration required.
