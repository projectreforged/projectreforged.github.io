⚡ Quick Install — Recommended for Kronos and unmodified 1.12 clients

🎮 Patched WoW.exe

Required Client ⚔️ Kronos

A pre-patched WoW.exe with two modifications already applied: VanillaTweaks and Vanilla Signature Removal. VanillaTweaks improves several 1.12 client limitations — including sound channels, nameplate range, terrain render distance, and Large Address Aware support (up to 4GB RAM). Signature Removal is required for addons that enable auto-login. Replace your original WoW.exe with this file.

⚠️ Tested and recommended for Kronos and unmodified vanilla 1.12 clients. If your client has already been modified, use the Manual Setup below instead.

Download

⚙️ VanillaFixes + DLL Pack

Required Launcher + Mods

VanillaFixes is an external launcher that fixes the stutter and animation lag caused by the 1.12 client's low-precision timer. It loads the DLL mods listed in dlls.txt at startup. Use it to launch the game instead of opening WoW.exe directly.

The included DLL Pack contains:

  • VfPatcher.dll — core VanillaFixes patcher
  • SuperWoWhook.dll — enables SuperWoW client extensions
  • VanillaHelpers.dll — required for Project Reforged to function
  • UnitXP_SP3.dll — unit frame and XP bar enhancements
  • nampower.dll — eliminates spell queue lag on the 1.12 client

Place all files in your World of Warcraft folder and ensure they are listed in dlls.txt.

🔧 Manual Install — For modified or incompatible clients

🔧 Manual Setup — Apply Patches Yourself

Alternative Advanced

For clients that cannot use the pre-patched WoW.exe above. Apply each tool individually, in the order listed.

1. VanillaTweaks
Download the release for your OS → extract vanilla_tweaks.exe into your WoW folder → drag WoW.exe on top of it. This creates WoW_tweaked.exe with all patches applied. Rename this file to WoW.exe (make a backup of your original one before).
Repository
2. Vanilla Signature Removal
Removes the executable signature check, required for auto-login addons. Download the tool, place it in your WoW folder, and run it pointing to your WoW.exe (or WoW_tweaked.exe if VanillaTweaks was already applied). The file will be modified in place.
Repository
3. VanillaFixes
External launcher that fixes stuttering and animation lag caused by the 1.12 client's low-precision timer. Also loads all DLLs listed in dlls.txt at startup. Download, extract into your WoW folder, and always use VanillaFixes.exe to launch the game — not WoW.exe directly.
Repository
4. SuperWoW
Adds modern client-side features used by advanced addons. Download SuperWoWhook.dll, place it in your WoW folder, and add its filename to dlls.txt. VanillaFixes will load it automatically at startup.
Repository
5. nampower
Fixes a structural flaw in the 1.12 client that adds extra latency between spell casts. Download nampower.dll, place it in your WoW folder, and add its filename to dlls.txt.
Repository
6. UnitXP SP3
Visual enhancements for XP bars and unit frames. Download UnitXP_SP3.dll, place it in your WoW folder, and add its filename to dlls.txt.
Repository
7. VanillaHelpers
Required for Project Reforged to function. Download VanillaHelpers.dll, place it in your WoW folder, and add its filename to dlls.txt.
Repository
