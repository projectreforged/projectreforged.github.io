v1.0.0
June 19th, 2026
Stable Release
▾
Version 1.0.0 marks the end of the beta period. Project Reforged WotLK is now in full stable release.
Patch A
  • All NPC textures across the game have been upscaled for improved quality. (Credits to Maribeth!)
Patch B
  • Fixed multiple texture glitches on Orc structures across Northrend, including the Horde Battle Ship in Icecrown.
Patch C
  • Fixed a texture glitch on the Big Blizzard Bear mount.
  • Fixed broken textures and particle effects on several bear mounts; models are now 33% larger.
  • Sergeant Gorth in Howling Fjord upgraded to a new HD model. (Credits: Kraulspine!)
  • Fixed NPC skin for Korra in Ashenvale.
  • Northshire Peasant upgraded to a new HD model. (Thanks to space_slam!)
  • Several creature models updated to match Space_slam's latest release.
  • Boar sizes in Durotar, Elwynn Forest, and Dun Morogh adjusted to proper scale.
  • Fel Reaver in Outland upgraded to a new HD model.
  • Fixed fire particle effects on the Warlock Level 20 mount; the eye and nose trail no longer persists while moving.
  • Fixed Murloc's portrait target camera.
  • Talbuk skin texture upgraded to UHD.
Patch D
  • Fixed tree models in Elwynn Forest that were causing shadow glitches when moving through certain areas.
  • Improved textures for Elwynn Forest tree leaves.
  • Replaced a bush model in Tirisfal Glades and Undercity for improved visuals.
  • Reduced the size of a tree in Stormwind that was clipping into the Mage Tower ramp.
  • Reduced the size of an oversized tree in Loch Modan.
  • Fixed floating body props in Tirisfal Glades near Scarlet Monastery and other affected areas.
  • Added a new HD tree to Stranglethorn Vale.
  • FixMap (by MacWarrior) is now incorporated into Patch-D, correcting the placement of several misaligned Blizzard assets that caused object clipping and floating in the original 3.3.5a client.
Patch E
  • Skybox updated to the latest version.
  • ObjectFade is now bundled into Patch-E, enabling smooth fade transitions for 3D objects and environment doodads. (All credits to Billy Hoyle!)
  • Fixed a lighting issue with the Eversong Woods grass texture; replaced with an upgraded version.
Patch G
  • Fixed transparency issues affecting several cloaks.
Patch I
  • Character Panel and Spellbook reverted to vanilla versions for compatibility reasons; they will return as an optional addon.
  • Patch-I is now fully compatible with ElvUI.
Patch M
  • No changes in this release.
Patch N
  • No changes in this release.
Patch P
  • Fixed a missing texture on the Rake ability for hunter pets.
Patch S
  • Restored character voice files that were conflicting with multi-language clients.
Patch U
  • Introduced as a new patch in v1.0.0.
  • Upright Orc model extensively reworked: all cloak geosets added with animations, one animated hairstyle included, and persistent seams around the ears resolved.
