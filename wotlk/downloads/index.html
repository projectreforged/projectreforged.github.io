Downloads

Project Reforged is fully modular — install only what you need. Start with the dependencies, then add patches at will.

Dependencies — Install First
🔧
WoW Patcher 3.3.5
Required
Patches your WoW 3.3.5 client to enable HD visual mods and interface edits. Run the patcher to enable both 4GB RAM and Allow Interface Edits before installing any patches.
Repository →
⚙️
DXVK 2.7.1
Recommended
Improves the Direct3D 9 rendering pipeline — better stability, performance, and compatibility, especially when using ReShade. Extract the archive, open the x32 folder, and copy d3d9.dll into your main WoW folder.
Download
Recommended Mods
✍️
Lexara — HD Font Renderer
Recommended
Replaces the WoW 3.3.5 font rendering engine with a high-definition MSDF renderer, producing crisp and clear floating combat text, nameplates, and UI fonts at any resolution. Follow the installation instructions in the repository.
Repository →
🔐
Vanguard — WotLK AutoLogin
Recommended
A GlueXML addon that automates the login process for WoW 3.3.5 private servers, saving your credentials securely and bypassing the login screen on launch. Read the README for setup instructions before use.
Repository →
Important: Patches B + D + E are one large environment/world set. Install them together, or not at all.
